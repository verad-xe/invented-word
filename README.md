One invented English word and its one-line definition — "fridgelurk (v.) — to open the fridge and stare inside, hoping something new has appeared since you last looked." — written to `entry.txt` for make.fun's "Invent a Word We Need" bounty. Running `main.py` writes exactly that line, plus a trailing newline, to `$MAKEFUN_OUTPUT_DIR/entry.txt`, after checking it against the gate (UTF-8 text, 1 to 140 characters, not only white space).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
